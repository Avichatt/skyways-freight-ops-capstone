# Definition of done, day by day

Two to three hours a day, five days a week. Ten working days plus five buffer days. Tick each row before you stop for the day. If a day's row is not ticked by the end of the next day, cut scope, do not stretch the calendar.

| Day | Done means | Commit message |
|---|---|---|
| 1 | Kit runs (`setup_check.py` passes), exploration notebook run end to end, three candidate pain points written down | "day1: environment and first look at the data" |
| 2 | Five Whys filled for all three candidates, at least two answers per sheet cite a query | "day2: five whys" |
| 3 | Depth matrix scored, one pain point chosen, PRD-lite drafted | "day3: pain point chosen, prd-lite" |
| 4 | Track and scope level chosen in an ADR, C4 context and container diagrams drawn, tool list or feature list fixed | "day4: scope and architecture" |
| 5 | Agentic: `understand` node and extraction prompt pass on 20 labelled messages. ML: cleaned data, baseline metric recorded | "day5: first working piece" |
| 6 | Agentic: `find_feasible_slots` returns correct slots for SHP1006 and SHP1015 (none). ML: first model beats baseline on a time split | "day6: feasibility / first model" |
| 7 | Agentic: hold and request work; `test_no_double_booking.py` passes. ML: second target or error bands; feature importance explained | "day7: commitment / second model" |
| 8 | Agentic: clarification and escalation paths pass EC03, EC04, EC06, EC10. ML: evaluation report filled. Hybrid: contract honoured end to end | "day8: edge cases" |
| 9 | Replay script demonstrates concurrency; all evaluation cases run; demo snapshot saved | "day9: proof" |
| 10 | README, architecture picture, ADRs in `docs/`, demo rehearsed once with a timer | "day10: documentation and rehearsal" |
| 11 to 13 (buffer) | Second rehearsal, LinkedIn post drafted, resume bullets written, one improvement if time remains | "buffer: polish" |
| 14 to 15 (buffer) | Final self-review checklist passed, submission made | "final" |
